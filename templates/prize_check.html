详细说明
一、浮动奖（一等奖、二等奖）
  • 一等奖：全部6个红球 + 1个蓝球全中。当期奖金封顶1亿元，按中奖注数均分。单注最高不超过500万元。
  • 二等奖：全部6个红球命中，蓝球未中。当期奖金封顶7000万元，按中奖注数均分。单注最高不超过46万元。
  • 浮动奖奖金分配比例：扣除固定奖总奖金后，一等奖占70%，二等奖占30%。
  • 当奖池资金低于1000万元时，一等奖奖金由奖池和调节基金补足至单注最高500万元。
二、固定奖（三至六等奖）
  • 三等奖：5红+1蓝中，固定奖金3,000元。
  • 四等奖：5红+0蓝 或 4红+1蓝中，固定奖金200元。
  • 五等奖：4红+0蓝 或 3红+1蓝中，固定奖金10元。
  • 六等奖：蓝球命中即中奖（红球任意），固定奖金5元。
三、福运奖 2026年新增

启用条件：当双色球奖池资金达到 15亿元 时，福运奖自动启用。

关闭条件：当奖池资金低于 12亿元 时，福运奖自动关闭。

中奖条件：3个红球命中 + 蓝球未中（即"3+0"）。

奖金：固定奖金 5元。

小提示：福运奖填补了传统规则中"3+0"不中奖的空白，大大提升了每注号码"保本"的机会。

四、中奖规则概要

单式号码（6红+1蓝）的中奖规则归纳：

  • 6+1 → 一等奖（浮动）
  • 6+0 → 二等奖（浮动）
  • 5+1 → 三等奖（3000元）
  • 5+0 → 四等奖（200元）
  • 4+1 → 四等奖（200元）
  • 4+0 → 五等奖（10元）
  • 3+1 → 五等奖（10元）
  • 3+0 → 福运奖（5元）
  • 2+1 → 六等奖（5元）
  • 1+1 → 六等奖（5元）
  • 0+1 → 六等奖（5元）
  • 其他 → 未中奖

注意：同一注号码不可同时中多个奖级，按最高奖金等级计算。

详细说明
一、浮动奖（一等奖、二等奖）
  • 一等奖：前区5个 + 后区2个全中。单期奖金封顶1亿元，基本投注单注最高1000万，追加投注最高1800万。
  • 二等奖：前区5个 + 后区1个命中。单期奖金封顶1亿元，基本投注单注最高500万，追加投注最高900万。

大乐透特色玩法。每注在2元基本投注基础上 增加1元，即可对 一、二等奖 进行追加。

  • 一等奖追加：基本奖金 + 追加奖金，合计最高1800万元
  • 二等奖追加：基本奖金 + 追加奖金，合计最高900万元
  • 三至七等奖：不参与追加投注
三、固定奖（三至七等奖）
  • 三等奖：5前+0后，基本5,000元 / 奖池联动6,666元
  • 四等奖：4前+2后，基本300元 / 奖池联动380元
  • 五等奖：4前+1后 或 3前+2后，基本150元 / 奖池联动200元
  • 六等奖：4前+0后 或 3前+1后 或 2前+2后，基本15元 / 奖池联动18元
  • 七等奖：3前+0后 或 2前+1后 或 1前+2后 或 0前+2后，基本5元 / 奖池联动7元
